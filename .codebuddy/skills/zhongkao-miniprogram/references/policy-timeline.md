# 广州中考年度政策时间线

> 权威来源：广州市招生考试委员会办公室 https://gzzk.gz.gov.cn/zkzz/zkxx/wjtz/

## 每年时间线（参考2025-2026年）

### 1月 - 年度政策发布
- [ ] 初三毕业班适应性测试通知（1月上旬）
- [ ] 普通高中招生工作负面清单发布
- [ ] 下年度中考计分科目方案（如适用）

### 2月 - 报名阶段
- [ ] 中考报名通知发布（2月下旬）
- [ ] 艺术学业水平考试报名
- [ ] 政策性照顾学生资格审核

### 3月 - 考试报名
- [ ] 中考正式报名
- [ ] 体育考试报名
- [ ] 英语听说考试报名
- [ ] 艺术学业水平考试

### 4月 - 招生计划
- [ ] 名额分配招生通知发布
- [ ] 体育艺术特长生招生计划
- [ ] 自主招生工作通知
- [ ] 实验操作考试范围公布
- [ ] 五年一贯制高职招生报名

### 5月 - 志愿填报
- [ ] 志愿填报工作通知（5月上旬）
- [ ] 符合名额分配资格考生名单公示
- [ ] 政策性照顾学生资格名单公示
- [ ] 志愿填报系统开放
- [ ] 中本贯通班招生（如适用）

### 6月 - 中考考试
- [ ] 中考文化课考试（6月中下旬）
- [ ] 体育考试完成
- [ ] 英语听说考试完成

### 7月 - 录取阶段
- [ ] 成绩公布（7月上旬）
- [ ] 梯度控制线公布（7月中旬）
- [ ] 各批次录取通知
- [ **提前批** ] 自主招生/特长生录取
- [ **第一批** ] 外国语/名额分配
- [ **第二批** ] 名额分配录取
- [ **第三批** ] 示范性/省一级高中录取
- [ **第四批** ] 其他普通高中录取
- [ ] 补录计划和办法公布
- [ ] 补录填报和录取

### 8月 - 收尾
- [ ] 中职学校录取
- [ ] 补录结果公布
- [ ] 新生注册报到

### 9月 - 新学年
- [ ] 高一新生入学

## 2026年特殊政策变化

根据2026年官方通知，需关注以下变化：
- **2027-2029年改革方案**已发布，可能涉及计分科目调整
- 中本贯通班试点项目（足球、舞蹈方向）
- 名额分配政策可能有微调

## 开发时间节点提醒

| 时间 | 开发任务 |
|------|----------|
| 6月底 | 确认当年梯度控制线 |
| 7月中旬 | 获取各批次录取分数线数据 |
| 7月下旬 | 更新学校数据、分数段统计 |
| 8月初 | 更新小程序版本、上线新数据 |

关键文件类型及对应时间：
- "做好高中阶段学校招生录取工作的通知" → 7月，录取规则
- "公布录取控制分数线的通知" → 7月，梯度线
- "公布高中阶段学校招生录取分数" → 7月，各校分数线
- "做好填报志愿工作的通知" → 5月，志愿填报规则
- "做好名额分配招生工作的通知" → 4月，名额分配规则
- "做好自主招生工作的通知" → 4月，自主招生规则
