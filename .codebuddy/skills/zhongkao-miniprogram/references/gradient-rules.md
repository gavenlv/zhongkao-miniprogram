# 梯度投档规则详解

## 什么是梯度投档

梯度投档是广州市中考录取的核心机制，将考生按分数划分为多个梯度，按梯度从高到低依次投档。同一梯度内的考生按志愿优先、分数优先的原则竞争。

## 梯度控制线的确定

梯度控制线在每年中考成绩公布后由广州市招考办划定。

### 划定方法
1. 以全市考生成绩排名为基准
2. 第一梯度线通常在全市排名前约10%的位置
3. 每个梯度之间固定间隔（通常为40分，具体以当年公布为准）
4. 最低梯度线即为普通高中最低录取控制线

### 2025年梯度控制线
| 梯度 | 控制线 | 分数范围 | 说明 |
|------|--------|----------|------|
| 第一梯度 | 707分 | ≥707分 | 最高梯度，约前10%考生 |
| 第二梯度 | 667分 | 667-706分 | |
| 第三梯度 | 627分 | 627-666分 | |
| 第四梯度 | 587分 | 587-626分 | |
| 第五梯度 | 547分 | 547-586分 | |
| 第六梯度 | 507分 | 507-546分 | |
| 普高最低线 | 487分 | 487-506分 | 低于此线无法录取普高 |

## 投档流程

### 总体流程
```
所有考生按分数排序
    ↓
从最高梯度开始投档
    ↓
同一梯度内：
  按志愿顺序投档（志愿优先）
    ↓
同一志愿内：
  按分数排序投档（分数优先）
    ↓
分数相同时：
  按同分序号排序
    ↓
该梯度投档完成后
    ↓
进入下一个梯度
    ↓
所有梯度投档完毕
```

### 第三批投档详细步骤

以一个具体例子说明：

**考生A：680分，户籍生，志愿填报**
1. 华师附中（第一志愿）
2. 广东实验中学（第二志愿）
3. 执信中学（第三志愿）

**投档过程：**

**第一步：确定梯度等级**
- 680分 ≥ 667分（第二梯度线）且 < 707分（第一梯度线）
- 考生A属于第二梯度

**第二步：检查学校录取情况**
假设投档进行到第二梯度时：
- 华师附中：第一志愿已录满（lastVolunteer=1）
- 广东实验中学：第一志愿未录满，正在录取第二志愿考生，最低分675分
- 执信中学：第一志愿已录满，第二志愿正在录取

**第三步：逐志愿投档**
1. **第一志愿 - 华师附中**：
   - 华师附中 lastVolunteer=1，考生在第1志愿
   - 考生680分 > 华师附中录取最低分740分？否
   - 680分 < 740分 → 第一志愿未录取

2. **第二志愿 - 广东实验中学**：
   - 广东实验中学当前在录取第2志愿考生
   - 考生680分 > 最低分675分 → 录取！

**结果**：考生A被广东实验中学录取（第2志愿）。

### 末位志愿的关键作用

末位志愿是理解梯度投档的关键概念：

**场景：** 某校有100个招生计划
- 第1志愿填报该校的考生有120人，且全部达到分数线
- 学校在第1志愿就录满了100人
- 此时 lastVolunteer = 1
- 第2、3志愿填报该校的考生即使分数更高也无法录取

**另一个场景：**
- 某校有100个招生计划
- 第1志愿填报该校的考生只有60人被录取
- 第2志愿填报该校的考生有50人，录取其中40人
- 此时 lastVolunteer = 2
- 第3志愿填报该校的考生有机会被录取

### 跨梯度录取

学校可以（且通常）在多个梯度录取考生：
- 知名学校可能在第一梯度就录满（lastVolunteer=1）
- 热门学校可能在第二梯度录满部分计划
- 普通学校可能录取到第四、第五梯度

### 考生策略建议

1. **合理定位**：根据自身分数确定所在梯度
2. **志愿拉开梯度**：6个志愿应覆盖不同层次的学校
3. **第一志愿要稳妥**：避免所有志愿都冲高
4. **了解末位志愿**：关注目标学校往年录取到第几志愿

## 同分排序规则

当考生总分相同时，按以下优先级逐一比较，排位靠前者优先录取：

| 优先级 | 比较项 | 说明 |
|--------|--------|------|
| 1 | 语数英三科总分 | 语文 + 数学 + 英语 |
| 2 | 数学单科 | 数学分数高者优先 |
| 3 | 语文单科 | 语文分数高者优先 |
| 4 | 英语单科 | 英语分数高者优先 |
| 5 | 道法+历史总分 | 道德与法治 + 历史 |
| 6 | 物理+化学总分 | 物理 + 化学 |

> 权威来源：广州市招生考试委员会办公室《高中阶段学校招生录取工作通知》每年发布。

## 第二批名额分配的特殊规则

### 与第三批的区别
- **竞争范围不同**：第三批全市竞争，第二批校内竞争
- **志愿数量不同**：第三批6个志愿，第二批3个志愿
- **录取控制线**：第二批设有最低录取控制线（通常为学校第三批录取线降20分）
- **报考资格**：需要满足名额分配报考资格（通常要求在同一初中读满3年）

### 投档流程
1. 筛选符合名额分配报考资格的考生
2. 按校内考生分数排序
3. 每所招生学校在该初中的分配名额单独计算
4. 志愿优先 + 分数优先（与第三批类似）
5. 达到最低录取控制线方可录取
