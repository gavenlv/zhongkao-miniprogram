# 梯度投档规则详解

## 录取批次总览

广州中考分为**四个批次**，按顺序依次投档录取。所有普高和中职批次均采用**梯度控制线上志愿优先**的投档方式：

| 批次 | 包含内容 | 志愿数 | 梯度适用 |
|------|----------|--------|----------|
| **第一批次** | 特长生、自主招生、外语艺术类、港澳子弟班、中本贯通、中职三二分段 | 各类1~4个 | 普高部分适用；中职以普高最低线为第一梯度线 |
| **第二批次** | 名额分配（公办示范性/省一级普高） | **3个** | 适用（仅户籍生） |
| **第三批次** | 示范性普高剩余计划、优质新建普高部分计划 | **6个** | **核心应用批次** |
| **第四批次** | 普通高中剩余、综合高中、中职学校剩余 | 各6个 | 普高部分适用 |

> **补录**：在第四批次中职学校录取之前进行。被前面批次录取后不再参加后续批次。

## 什么是梯度投档

梯度投档是广州市中考录取的核心机制，将考生按分数划分为多个梯度，按梯度从高到低依次投档。同一梯度内的考生按志愿优先、分数优先的原则竞争。

## 梯度控制线的确定

梯度控制线在每年中考成绩公布后由广州市招考办划定。

### 划定方法
1. 以全市考生成绩排名为基准
2. 第一梯度线通常在全市排名前约10%的位置
3. 每个梯度之间固定间隔（通常为40分，具体以当年公布为准）
4. 最低梯度线即为普通高中最低录取控制线

### 2025年梯度控制线
| 梯度 | 控制线 | 分数范围 | 说明 |
|------|--------|----------|------|
| 第一梯度 | 707分 | ≥707分 | 最高梯度，约前10%考生 |
| 第二梯度 | 667分 | 667-706分 | |
| 第三梯度 | 627分 | 627-666分 | |
| 第四梯度 | 587分 | 587-626分 | |
| 第五梯度 | 547分 | 547-586分 | |
| 第六梯度 | 507分 | 507-546分 | |
| 普高最低线 | 487分 | 487-506分 | 低于此线无法录取普高 |

## 投档流程

### 总体流程
```
所有考生按分数排序
    ↓
从最高梯度开始投档
    ↓
同一梯度内：
  按志愿顺序投档（志愿优先）
    ↓
同一志愿内：
  按分数排序投档（分数优先）
    ↓
分数相同时：
  按同分序号排序
    ↓
该梯度投档完成后
    ↓
进入下一个梯度
    ↓
所有梯度投档完毕
```

### 第三批投档详细步骤

#### 完整判定流程（三大分支）

投档前先进行**资格检查**：分数有效 → 确定梯度等级 → 检查普高线门槛 → 过滤有效志愿。

对每个志愿，根据**学校录取线与考生梯度的关系**，分三个分支处理：

---

##### 分支A：跨梯度投档

当学校最低录取分数所在梯度 **低于** 考生所在梯度时触发。
例如：考生680分（第二梯度），某校录取线650分（第四梯度）。

| 条件 | 结果 | 原因 |
|------|------|------|
| 考生分数 > 学校最低分 | **录取** | 学校在高梯度未招满，有剩余计划 |
| 考生分数 = 最低分 且 同分序号OK | **录取** | 同上 + 同分排序通过 |
| 其他情况 | 未录取 | 分数不够 |

---

##### 分支B：同梯度·学校已满

当学校的末位录取考生分数 >= 考生梯度控制线时触发。
说明学校在当前梯度早期就录满了。

**关键门禁 — 末位志愿截断**：
- 若 `末位志愿序号 < 当前填报志愿序号` → **直接跳过该校**，不进行任何比较
- 这是梯度投档最核心的机制

门禁通过后，选择比较基准：
- 当前志愿 = 末位志愿 → 用 `(末位考生分数, 末位同分序号)` 比较
- 当前志愿 < 末位志愿 → 用 `(学校最低分, 最低分同分序号)` 比较

| 条件 | 结果 |
|------|------|
| 考生分数 > 比较基准 | **录取（分数优先）** |
| 考生分数 = 比较基准 且 同分序号OK | **录取（同分序号通过）** |
| 其他 | 未录取 |

---

##### 分支C：同梯度·学校未满

当学校的末位录取考生分数 < 考生梯度控制线时触发。
说明学校在前面的梯度都没招满，当前梯度还有剩余计划。

| 条件 | 结果 |
|------|------|
| 考生分数 > 最低分 | **录取（梯度内）** |
| 考生分数 = 最低分 且 同分序号OK | **录取（梯度内+同分）** |
| 其他 | 未录取 |

---

#### 具体案例

**考生A：680分，户籍生，同分序号=50，志愿填报**
1. 华师附中（第一志愿）
2. 广东实验中学（第二志愿）
3. 执信中学（第三志愿）

假设各校数据：
- 华师附中：户籍最低740分，末位志愿=1，末位分740分
- 广东实验中学：户籍最低675分，末位志愿=2，末位分672分
- 执信中学：户籍最低660分，末位志愿=3，末位分650分

**投档过程：**

考生680分在 **第二梯度**（控制线667分）

**第一志愿 - 华师附中：**
- 学校最低分740分在 **第一梯度**（> 第二梯度）→ 进入分支B
- lastVolunteer=1, volunteerOrder=1, 门禁通过
- compareScore = lastScore = 740
- 680 < 740 → **未录取**

**第二志愿 - 广东实验中学：**
- 学校最低分675分也在 **第一梯度**（>= 第二梯度控制线667）→ schoolFinishedInCurrentGradient=true
- lastVolunteer=2, volunteerOrder=2, 门禁通过
- volunteerOrder(2) == lastVolunteer(2) → compareScore = lastScore = 672
- 680 > 672 → **录取！第2志愿，分数优先录取**

### 末位志愿的关键作用

末位志愿是理解梯度投档的关键概念：

**场景：** 某校有100个招生计划
- 第1志愿填报该校的考生有120人，且全部达到分数线
- 学校在第1志愿就录满了100人
- 此时 lastVolunteer = 1
- 第2、3志愿填报该校的考生即使分数更高也无法录取

**另一个场景：**
- 某校有100个招生计划
- 第1志愿填报该校的考生只有60人被录取
- 第2志愿填报该校的考生有50人，录取其中40人
- 此时 lastVolunteer = 2
- 第3志愿填报该校的考生有机会被录取

### 跨梯度录取

学校可以（且通常）在多个梯度录取考生：
- 知名学校可能在第一梯度就录满（lastVolunteer=1）
- 热门学校可能在第二梯度录满部分计划
- 普通学校可能录取到第四、第五梯度

### 考生策略建议

1. **合理定位**：根据自身分数确定所在梯度
2. **志愿拉开梯度**：6个志愿应覆盖不同层次的学校
3. **第一志愿要稳妥**：避免所有志愿都冲高
4. **了解末位志愿**：关注目标学校往年录取到第几志愿

## 同分排序规则

当考生总分相同时，按以下优先级逐一比较，排位靠前者优先录取：

| 优先级 | 比较项 | 说明 |
|--------|--------|------|
| 1 | 语数英三科总分 | 语文 + 数学 + 英语 |
| 2 | 数学单科 | 数学分数高者优先 |
| 3 | 语文单科 | 语文分数高者优先 |
| 4 | 英语单科 | 英语分数高者优先 |
| 5 | 道法+历史总分 | 道德与法治 + 历史 |
| 6 | 物理+化学总分 | 物理 + 化学 |

> 权威来源：广州市招生考试委员会办公室《高中阶段学校招生录取工作通知》每年发布。

## 第二批名额分配（官方完整规则）

### 政策定位

公办的示范性普通高中学校（含国家级和市示范性）和省一级普通高中学校，须将不低于**50%的招生计划**分配到全市各初中学校。第二批即"名额分配"批次，是户籍生升入优质公办高中的核心途径。

### 招生学校范围及分配方向

| 学校类型 | 分配方向 | 说明 |
|----------|----------|------|
| 省、市属普通高中 | 面向**全市**初中学校分配 | 如华师附中、省实、广雅、执信等 |
| 区属普通高中 | 仅面向**本区**初中学校分配 | 老三区（越秀/海珠/荔湾）按三个独立招生区域进行 |

> **老三区跨区限制**：越秀区初中学校不能分配到荔湾区或海珠区的区属普高名额，反之亦然。但老三区考生可以报考省/市属高中的名额分配（面向全市）。

### 报考资格（须同时满足3个条件）

1. **初中应届毕业生**
2. **具有广州市户籍**（含政策性照顾学生）
3. **三年完整学籍**：具有广州市同一初中学校三年完整学籍并在该校就读到毕业；或从市外转学到本市并在转入初中学校就读到毕业

> 资格由初中学校审核，不需考生自行申报。**普通非户籍生（随迁子女）不能参与名额分配**。

### 录取控制线

- **计算公式**：该校近三年统招首批次户籍生录取最低分的平均值 **下降40分**（去尾取整）
- **底线要求**：不得低于当年全市普通高中录取最低控制分数线
- **注意**：降分设定控制线 ≠ 降分录取。达到控制线仅是录取的必备条件之一。

### 志愿设置

- 所在批次：第二批次（独立批次、独立录取）
- 志愿数量：**3个**学校志愿
- 与其他批次同步填报志愿

### 投档规则（梯度控制线上志愿优先）

1. **投档比例**：按 **1:1 比例**投档
2. **门槛过滤**：考生分数必须达到所报高中的名额分配最低录取控制线，才有资格进入梯度投档池
3. **分梯度投档**：先用梯度投档控制线将考生按成绩分成若干档，从高梯度到低梯度依次投档
4. **梯度内志愿优先**：
   - 同一梯度内，先投所有考生的**第一志愿**，按分数从高到低录取
   - 若该校在当前初中的分配名额已用完，不再投档后续考生
   - 第一志愿投完后，再投**第二志愿**，依此类推
5. **同分排序**（分数相同时按以下优先级比较）：
   - 语数英三科总分 → 数学单科 → 语文单科 → 英语单科 → 道德与法治 → 历史 → 物理 → 化学

### 加分及参考科目限制

- **不享受加分**：名额分配录取不享受加分或优先录取，只看原始投档分
- **参考科目要求**：
  - 示范性普高：地理、生物学、信息科技、艺术均须达到 **C级及以上**
  - 非示范性普高：均须达到 **D级及以上**

### 未完成计划处理

第二批次名额分配招生计划如果投档未完成，**剩余计划均并入该校第三批次或第四批次计划**，不进行降分录取。

### 校内竞争的核心特点

- **校内排名决定**：录取结果取决于考生在本初中学校内的相对排名，而非全市排名
- **各校录取分不同**：同一所高中在不同初中的实际录取分数往往不同（取决于该校分配到的名额数和该校考生的整体水平）
- **排序优先级**：判断两名考生谁先被录取 → 先比梯度高低 → 再比志愿顺序 → 最后比分数
