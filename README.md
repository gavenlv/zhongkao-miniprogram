# 广州中考投档系统 - 微信小程序

基于2025年广州市中考投档录取规则开发的微信小程序，提供模拟填报和投档流程展示功能。

## 功能特点

### 1. 模拟填报
- 输入中考分数和考生类型（户籍生/非户籍生）
- 填报最多6个志愿学校
- 实时计算录取结果
- 详细展示投档录取过程

### 2. 投档流程
- 主流程展示：梯度投档、志愿优先、分数优先等原则
- 梯度内流程：同一梯度内的投档处理
- 志愿落榜处理：第1志愿落榜后的处理流程
- 梯度落榜处理：整个梯度落榜后的降档流程

## 技术实现

### 投档规则
严格按照广州市中考投档录取规则实现：
1. **梯度投档优先原则**：高分优先投档，先投第一梯度考生
2. **同一梯度内志愿优先**：同一梯度考生，按志愿顺序投档
3. **分数优先原则**：同一志愿内，分数高的考生优先录取
4. **同分序号判定**：分数相同按同分序号排序
5. **末位志愿判定**：学校在某志愿完成招生，后续志愿不再录取

### 数据来源
- 学校数据：2025年广州市普通高中第三批录取数据
- 梯度控制线：
  - 第一梯度：≥707分
  - 第二梯度：667-706分
  - 第三梯度：627-666分
  - 第四梯度：587-626分
  - 第五梯度：547-586分
  - 普高最低线：487-546分

## 使用说明

### 开发环境
1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入项目：选择 `zhongkao-miniprogram` 目录
3. 在 `project.config.json` 中修改 `appid` 为你的小程序AppID

### 添加图标（可选）
在 `images` 目录下添加以下图标文件：
- `volunteer.png` - 模拟填报图标（未选中）
- `volunteer-active.png` - 模拟填报图标（选中）
- `flowchart.png` - 投档流程图标（未选中）
- `flowchart-active.png` - 投档流程图标（选中）

然后在 `app.json` 的 `tabBar.list` 中添加 `iconPath` 和 `selectedIconPath` 配置。

### 发布上线
1. 在微信开发者工具中点击"上传"
2. 登录微信公众平台提交审核
3. 审核通过后发布上线

## 核心算法

### 录取计算流程
```javascript
1. 检查分数是否达到普高最低控制线
2. 遍历所有志愿学校
3. 对每个志愿：
   a. 检查学校是否已在更早志愿完成招生
   b. 比较考生分数与学校录取线
   c. 处理同分情况（同分序号比较）
   d. 返回录取结果
```

### 关键判定条件
- **末位志愿判定**：若学校末位志愿 < 考生志愿序号，则该校不会录取该考生
- **分数判定**：考生分数 > 学校最低录取线，可录取
- **同分判定**：考生分数 = 学校最低录取线，且同分序号 ≤ 学校录取同分考生最大序号，可录取
