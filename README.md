# 广州中考投档系统 - 微信小程序

基于广州市中考实际录取数据（2023-2026年）开发的微信小程序，帮助考生和家长理解投档规则、模拟志愿填报、分析录取概率。严格遵循[广州市招生考试委员会办公室](https://gzzk.gz.gov.cn/zkzz/zkxx/wjtz/)发布的官方政策。

> **已上线**，可在微信搜索使用。

## 功能特点

### 1. 录取规则展示
- 梯度投档、志愿优先、分数优先等核心规则的流程图解
- 梯度控制线可视化展示
- 基于真实数据的典型录取案例分析（第三批10个 + 名额分配5个）

### 2. 第三批模拟填报（示范性/省一级高中）
- 输入中考总分、考生类型（户籍生/非户籍生）、同分序号
- 最多填报6个志愿学校
- 实时计算录取结果，展示完整投档过程
- 支持2025年数据模拟 + 2026年预测模拟

### 3. 第二批模拟填报（名额分配招生）
- 校内竞争模式（与同校同学竞争）
- 最多填报3个志愿学校
- 分户籍生/非户籍生分别计算
- 支持2025年数据模拟 + 2026年预测模拟

### 4. 历史数据查询
- 2023-2025年各校录取分数线对比
- 各校录取变化趋势图
- 分数段统计与排名估算

### 5. 2026年预测
- 根据初三适应性测试成绩估算中考分数
- 基于估算分数进行模拟填报
- 支持第三批和第二批双通道预测

## 技术实现

### 投档规则（严格按照官方政策实现）

1. **梯度投档优先原则**：高分梯度优先投档（第一梯度约前10%考生，每级间隔40分）
2. **同一梯度内志愿优先**：按志愿顺序依次投档
3. **分数优先原则**：同一志愿内高分考生优先
4. **同分序号判定**：分数相同时按优先级排序 — 语数英三科总分 > 数学单科 > 语文单科 > 英语单科 > 道法+历史总分 > 物理+化学总分
5. **末位志愿判定**：学校在某志愿完成招生，后续志愿不再录取该校考生

## 核心算法

### 第三批录取计算流程

```
输入：考生分数、户籍类型、志愿列表、同分序号
  ↓
1. 考生分数 < 普高最低控制线 → 未达线
2. 确定考生所在梯度等级（getGradientLevel）
3. 按志愿顺序逐一投档：
   a. 末位志愿判定：lastVolunteer < 当前志愿序号 → 跳过
   b. 选择对应分数线（户籍生 hukou / 非户籍 nonHukou）
   c. 分数 > 最低分 → 录取
   d. 分数 = 最低分 → 比较同分序号
   e. 分数 < 最低分 → 未录取
4. 所有志愿未录取 → 滑档
  ↓
输出：录取结果 + 详细投档过程
```

### 第二批名额分配特殊逻辑
- 校内竞争模式：考生与同校考生竞争分配名额
- 设有最低录取控制线（通常为学校第三批录取线降20分）
- 3个志愿，分户籍生/非户籍生分别录取
